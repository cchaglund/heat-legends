---
name: create-prd
description: Convert the feature request into structured PRD items.
---

If you are not provided with a feature request, look for it in "features/current-feature" as "feature-request.md".

Convert the feature request into structured PRD items. Each item should have: id, category, description, steps to verify, and passes: false. Format as JSON. Be specific about acceptance criteria. Save this PRD as PRD.json in "features/current-feature", or next to the passed feature request. If you are unsure about any aspect of the feature request, e.g. if something is unclear, ask clarifying questions before proceeding. If, after receiving answers to questions, you need to modify the feature request, go ahead and do that. Your job is to create a clear and detailed PRD from the feature request, so they should be as closely aligned as possible.
